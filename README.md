# DentalKab

Single-page dental clinic landing page. React + Vite + TypeScript + Tailwind CSS, no external UI or icon libraries.

## Stack

- [Vite](https://vite.dev/) + React 19 + TypeScript
- Tailwind CSS 3

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
